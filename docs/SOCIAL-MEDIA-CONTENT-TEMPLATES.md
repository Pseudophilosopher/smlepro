## 🎨 Design Guidelines

### Color Palette
- **Primary:** #11b4d4 (Cyan)
- **Accent:** #D4AF37 (Gold)
- **Dark:** #0a0a0a (Black)
- **Light:** #ffffff (White)

### Typography
- **Arabic:** Noto Sans Arabic
- **English:** Space Grotesk

### Image Style
- Clean, modern, professional
- Medical symbols (stethoscope, caduceus)
- Saudi cultural elements (flag colors, patterns)
- Glassmorphism effects (matching app design)

## 📊 Performance Tracking

### Metrics to Monitor
- **Engagement Rate:** (Likes + Comments + Shares) / Followers
- **Reach:** Unique accounts that saw content
- **Click-through Rate:** Link clicks / Impressions
- **Conversion Rate:** Website visits / Social clicks

### Weekly Review Questions
1. Which content type performed best?
2. What time got the most engagement?
3. Which hashtags drove most reach?
4. What questions did audience ask?
5. How can we improve next week?
